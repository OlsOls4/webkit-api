# WebKit API family
One Cloud Run service (auto-deployed from main) hosting four APIs, each listed separately on RapidAPI:
- WebKit (root): /email/validate, /url/preview, /url/extract
- DomainKit (/domain): /dns, /ssl, /whois, /scan
- QRKit (/qrkit): /qr, /qr/wifi, /qr/vcard, /barcode
- TextKit (/text): /language, /sentiment, /readability, /keywords, /profanity, /summarize, /slugify, /stats, /analyze
- CurrencyKit (/fx): /latest, /convert, /historical, /timeseries, /currencies (ECB euro reference rates)
- VATKit (/vat): /check (live VIES), /format, /rates, /status
