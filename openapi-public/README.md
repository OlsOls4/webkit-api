# Public OpenAPI definitions

OpenAPI 3.0 definitions for the 13 APIs published on RapidAPI by [Olly-1VN9JTXKG](https://rapidapi.com/user/Olly-1VN9JTXKG). Every API is called through the RapidAPI gateway (`https://<api>.p.rapidapi.com`) with the `X-RapidAPI-Key` and `X-RapidAPI-Host` headers; each has a free BASIC plan. Each API also exposes an MCP (Model Context Protocol) server at `/mcp` on the same host.

These files are the directory-facing copies used for listings such as APIs.guru.
